# 📝 Solution Format

Every problem should follow the same format.

```swift
/*
 Problem: Two Sum
 Difficulty: Easy
 Pattern: HashMap

 Time Complexity: O(n)
 Space Complexity: O(n)

 Approach:
 1. Store previously seen values in a dictionary.
 2. Calculate the required complement.
 3. Check whether the complement already exists.
 4. Return the indices when found.
*/

func twoSum(_ nums: [Int], _ target: Int) -> [Int] {
    var map: [Int: Int] = [:]

    for (index, num) in nums.enumerated() {
        let complement = target - num

        if let previousIndex = map[complement] {
            return [previousIndex, index]
        }

        map[num] = index
    }

    return []
}
```
